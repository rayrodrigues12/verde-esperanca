# Verde Esperança — Projeto Acadêmico

Site estático de três páginas desenvolvido em HTML5 e CSS3 para uma ONG fictícia de proteção ambiental.

## Estrutura
- `index.html` — página inicial
- `projetos.html` — projetos, atividades e tabela
- `contato.html` — contato, voluntariado e formulário
- `css/style.css` — folha de estilos externa
- `images/` — imagens do projeto

O projeto foi preparado para atender aos requisitos acadêmicos de HTML semântico, navegação, imagens, hiperlinks, listas, tabela, formulário e CSS externo.

## Como abrir
Abra `index.html` diretamente no navegador. Não é necessário npm, React ou servidor local.
